# Design

## Context

現有 Guided Notes parser 可處理多工作表，但 adapter 會依連結 `gid` 限制讀取；匯出快照已保存選定工作表 ID。匯出結構比對目前遇到第一項差異就停止回報，不能同時列出多題錯誤。CSV 目前是四欄格式，未防範試算表將答案視為公式。結束階段老師 API 已只回傳有效提交；這次明確把此行為寫進規格並保留回歸驗收。老師即時監看目前直接把提交資料渲染到頁面，投影時需要前端預設收起且避免建立含答案的 DOM。

## Goals / Non-Goals

**Goals:**
- 讓匯入選擇完全依工作表順序，忽略連結 `gid`；匯出固定重讀匯入時記錄的工作表 ID。
- 對匯出前的題目結構與本機填空格一致性做全量預檢；任何問題都在單次 batchUpdate 前彙整並中止。
- 提供指定五欄、每填空一列且對 Excel 安全的勝出組 CSV。
- 投影時預設隱藏老師即時作答狀況，隱藏時不把作答資料放入 DOM。
- 維持已結束老師 API 不包含已取代提交內容，並保留 DB 歷史。

**Non-Goals:**
- 不改變伺服器提交、順位計算、教師 API 的資料提供範圍或 Google Sheet 純文字寫入內容。
- 不將 `gid` 當成工作表選擇或匯出一致性條件。
- 不在本次修改 README、驗收矩陣以外的產品行為，也不新增資料庫 schema。

## Decisions

### 工作表順序選擇與匯出錨定

- Sheets adapter 匯入時不依 URL query 或 fragment 的 `gid` 篩選；傳入來源 URL，回傳工作表清單及格值，保留 Google API 工作表順序。`read_structure` 可選擇性接受 `worksheet_id`，只供匯出重讀時使用。
- Parser 依順序略過沒有同一列完整「題號」與「作答」標題的分頁，選第一個符合者；選定分頁若有多標題列、重複題號或題格歧義，直接失敗，不嘗試後頁。含 `gid` 的 URL 與不含 `gid` 的 URL 完全相同處理。
- 匯出由保存的快照 `worksheet_id` 指定重讀目標；其他分頁的標題、順序或內容不改變匯出目標。不得把匯入來源 URL 中的 `gid` 當一致性判斷。

### 匯出全量預檢及錯誤彙總

- 在呼叫 `write_answers` 前先完成重新讀取、解析、來源／工作表層級比對、所有題號與順序比對、每題填空數與座標比對，以及本機 `answer_cells` 數量核對。比對需掃描完整快照，不採遇到第一項差異立即 return。
- 將題目層級問題以題號集合彙總，錯誤訊息列出全部問題題號及各自原因；題目新增、刪除、重排、填空數／順序／位置差異均納入。試算表來源、工作表 ID／名稱、標題列或欄位位置等工作表層級問題指出欄位和差異原因。兩類同時存在時可同一錯誤回報。
- 若重新解析本身失敗並產生 `SheetParseError`，只回報 parser 的第一個錯誤位置，不彙整其他題號；「列出全部問題題號」僅適用於可成功解析、再與匯入快照比較發現結構差異的情況。
- 任一解析或比對錯誤時都不呼叫 adapter 寫入；必須等全部前置驗證通過後才組裝一個批次更新。沒有勝出答案的題仍不寫入。

### CSV 安全序列化

- CSV 每個勝出題的填空各一列，欄序固定為「題號、組別、填空序號、答案、搶答順位」，填空序號從 1 起；一題無人提交時不產生答案列。僅已結束且通過老師驗證的 session 可下載。
- 先對答案欄檢查第一個字元。若為 `=`, `+`, `-`, `@`, Tab、CR 或 LF，在該答案字串前加單引號；只改 CSV 序列化值，不改題號等其他欄位，也不改 Google Sheet 匯出的 `stringValue`。
- 使用 RFC 4180 相容 CSV writer 處理逗號、雙引號、CR/LF，使用 CRLF 記錄分隔，最後編碼成 UTF-8 並加 BOM。CSV 測試同時比較完整位元組／字串結果與欄位解析結果。

### 老師結束回應與即時監看

- 已結束老師 API 目前在 `get_quiz_view` 將提交 rows 篩成 `is_effective` 後回傳；維持此行為並以測試確認回應沒有舊提交答案文字。資料庫仍保留所有提交歷史。搶答中的老師 API 不變。
- 老師即時監看僅在 active phase 提供 toggle。初次載入 active 畫面預設 collapsed；每次 poll redraw 前後以記憶體布林狀態保存展開值。Collapsed 時只渲染標題與「顯示作答狀況」控制，不建立題目作答數、提交列、組別、答案或順位節點。切換成 ended 時直接展開結束結果；已結束頁面無需點擊即顯示。
- 展開狀態不寫入 session/local storage；完整頁面重新載入後重新採用 active 預設收起。這只保護投影畫面／DOM，教師 API 仍可回傳即時監看資料，README 必須明確說明並要求老師驗證。

### 規劃文件與驗收記錄

- README 說明無視 `gid`、匯出全量中止與問題題號彙總、CSV 欄位／危險前綴僅作用於 CSV、老師監看投影限制及人工驗證步驟。
- `docs/acceptance-matrix.md` 對應各新增 scenario 的測試名或人工驗證；真實 Sheets 及 DOM 投影檢查標記人工項目。

### 誤提交 SQLite 檔與忽略規則

- 已依 task 使用 `git rm -- "貼上視窗 A 的資料庫路徑"` 移除指定追蹤檔，未讀取內容；`.gitignore` 已增加明確忽略規則並以 `git check-ignore` 測試。

## Risks / Trade-offs

- 忽略 `gid` 可能讓使用者以為連結錨定分頁 → README 說明系統總是依分頁順序採第一個完整標題頁，匯入摘要顯示實際工作表。
- 同時回報多題結構錯誤需要先完整掃描快照 → 前置預檢彙總所有題目差異，確保錯誤友善且零寫入。
- CSV 單引號前綴會成為 CSV 欄位字面內容 → 明確僅防止試算表將特定開頭解讀為公式，原 Sheet 保持原答案。
- collapsed DOM 不能防止老師 API 資料被有權限者查詢 → README 清楚說明只提供投影畫面保護，不作為 API 資安邊界。

## Migration Plan

無資料庫 schema migration。既有匯入快照已有 `worksheet_id`，可用於匯出指定讀取；CSV 格式與匯出錯誤回報改版後生效。清理工作已完成，後續工作聚焦其餘行為。

## Open Questions

無。選頁、全量中止、CSV 公式前綴及監看畫面顯示規則均由需求指定。
