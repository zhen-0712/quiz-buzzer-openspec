# Proposal

## Why

後續使用發現 Guided Notes 解析需要明確支援多工作表並拒絕重複題號；目前結束後的老師畫面包含已被重送取代的提交，且學生頁面輪詢重畫時會讓送出按鈕停用或清除其他題的未送出草稿。另有一個誤提交的 SQLite 檔需要從版本控制移除。

## What Changes

- 更新 Guided Notes 工作表選擇規則：依工作表順序採用第一個含同列「題號」與「作答」標題的工作表，略過非候選工作表；網址含 `gid` 時只讀指定工作表。候選工作表內的標題或題目結構有歧義時立即失敗，不改採後續工作表。
- 拒絕同一工作表內再次出現的非相鄰題號區塊，錯誤指出題號與位置；合併題號涵蓋的多列仍屬同一題。
- 匯出前固定依匯入時保存的工作表識別碼重新解析與比較結構。
- 老師結束畫面只列每組每題最新有效提交及其順位；提交歷史仍保留於資料庫。相同內容的有效重送也建立新提交並取得新序號。
- 修正學生提交完成後按鈕未恢復及輪詢重畫造成草稿遺失；成功題可清空，其他題和失敗題草稿保留。
- 規劃移除根目錄誤提交 SQLite 檔，並驗證 `.gitignore` 涵蓋該檔與暫存資料庫。
- 更新 README 與驗收情境對照表，記錄新增行為和測試／人工驗證方式。

## Capabilities

### Modified Capabilities

- `guided-notes-import`: 多工作表與 `gid` 選擇規則、拒絕非相鄰重複題號。
- `sheets-export`: 匯出結構比對鎖定匯入時選定的工作表。
- `quiz-buzzer`: 結束後老師只檢視每組每題最新有效提交；相同答案重送仍是新提交；學生表單可重送並保留未送草稿。

## Impact

- 影響 Guided Notes parser、Sheets adapter 的讀取選擇、匯出結構比對、老師結束畫面與學生頁面 JavaScript。
- 增補假 Sheets adapter／parser／API 測試；若現有 pytest 環境無法執行瀏覽器 JavaScript，README 將記錄可重現的手動驗證步驟。
- 移除誤提交 SQLite 檔並調整或驗證 `.gitignore`。
